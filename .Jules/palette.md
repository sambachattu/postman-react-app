## 2024-09-13 - Icon-Only Button Accessibility and Tooltips\n**Learning:** Testing elements by an empty name string (e.g., `{ name: '' }`) is a brittle anti-pattern that hides accessibility issues. Icon-only buttons must include `aria-label` for screen readers and `title` for mouse hover tooltips to ensure usability.\n**Action:** When adding or modifying icon-only buttons, always include both `aria-label` and `title` attributes, and ensure tests use the newly added accessible name.
