## YYYY-MM-DD - Empty Button Name Tests Anti-Pattern\n**Learning:** Relying on querying elements by an empty string (e.g., `screen.getAllByRole('button', { name: '' })`) in React Testing Library is a brittle anti-pattern that hides significant accessibility issues (like missing `aria-label` attributes on icon-only buttons).\n**Action:** When adding accessible names to previously unlabelled elements, always update the associated tests to assert against the new, correct `name` value, ensuring the test now actively enforces accessibility.
